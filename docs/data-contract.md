# 降水情景口径

OH、MH、MF、template各行为station/day/season/mm，mm非负。每站季节样本非空，无隐式缺测填补；输入缺少所需站季节时拒绝订正。midrank对某未来值x用p=(小于x的个数+0.5*等于x的个数)/n。参考分位type-7以(n-1)*p插值，n=1为唯一值，不在端点外外推。

目标干日数的比例计算用实际样本频率，不用经验分位中点代替。目标个数为floor(p*n+0.5)。置零选择按(原始订正值,MF日期)排序，原始订正包含截零前后两值。模板恢复在每站季节独立进行，但该季节的模板窗、日期集合与所有站相同；模板按(mm,day)排序，未来最终值按(value,MF日期)稳定排序。恢复输出的时间身份仍为未来窗的日期顺序，模板日期只提供对应秩位置，不覆盖未来日期。

现有domain不求分位、不订正、不恢复排序，仅核对原始资料。
